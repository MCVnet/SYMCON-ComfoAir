# Lizenz und Bildnutzungsrechte

Vor einer öffentlichen Lizenzvergabe ist festzustellen, wer die Rechte am Modulcode, an eingebetteten grafischen Darstellungen und an Dokumentation besitzt. Dieses Paket fügt bewusst **keine ungeprüfte MIT-/Apache-/GPL-Lizenz** hinzu.

Das Zehnder-Warenzeichen wird ausschließlich beschreibend zur Benennung kompatibler Produkte benutzt. Das Projekt ist **nicht offiziell mit Zehnder verbunden**. Das Gerätebild ist generiert und stellt kein offizielles Produktfoto dar.

Für die öffentliche Veröffentlichung die Lizenzentscheidung und etwaige Bildnutzungsrechte ausdrücklich dokumentieren.
